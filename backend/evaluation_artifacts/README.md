# Harness routing evaluation artifacts

Files in this directory are complete provider prediction freezes generated by
`scripts/run_harness_routing_campaign.py`. They contain no API keys, provider
request IDs, user data, or simulator secrets.

Each file is bound to the canonical development corpus, exact production prompt
suite, Evidence/Tool/Prompt versions, provider, immutable model snapshot when
available, response-format configuration, selected tools, and bounded
rationales. Validate one with:

```powershell
cd backend
.venv\Scripts\python.exe scripts\evaluate_harness_router.py `
  --predictions evaluation_artifacts\<artifact>.json
```

These artifacts qualify routing discrimination only. They do not establish that
LLM routing improves final simulation outcomes over a budget-matched
deterministic optimizer campaign.
