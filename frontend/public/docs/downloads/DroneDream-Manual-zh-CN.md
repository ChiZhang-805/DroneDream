# DroneDream 使用说明书

**版本 1.0.0 · Windows 10/11 x64**

DroneDream 是一个本地优先的 PX4 控制参数调优工作台，用来统一完成实验设计、候选搜索、Gazebo 仿真、结果比较和证据留存。它既支持通过对话快速生成草稿，也保留了确定性的参数边界、场景矩阵、仿真执行和验收规则。

> **工程边界**
>
> DroneDream 可以提出和比较候选参数，但仿真结果不能自动成为真实硬件的飞行许可。任何被选中的参数组合都必须先通过独立的 SITL 验证，之后才可以考虑真实硬件。

## 1. 开始之前

DroneDream 把飞行设置、参数范围、场景定义、优化预算和结果证据组织在一套可以复查的流程中。大语言模型可以帮助理解需求并准备草稿，但字段校验、耦合规则、仿真执行和验收判断始终由确定性的工程流程控制。

进入调优工作台前请确认：

- 使用 Windows 10 或 Windows 11 的 x64 计算机；
- 在可写入的 NTFS 磁盘上预留至少 52 GiB 空间；
- 创建 DroneDream 账户，使草稿和账户设置始终属于正确的用户；
- 只有需要调优对话或大模型策略时才配置模型；
- 实验运行期间保持应用开启，除非任务详情已经显示安全的终止状态。

## 2. 安装与环境准备

### 2.1 下载并安装

从 [getdronedream.com](https://getdronedream.com) 下载当前安装程序。运行安装包，选择符合条件的本地磁盘；除非计算机有明确的存储策略，否则保留推荐的应用目录。

### 2.2 准备本地运行环境

首次启动时，DroneDream 会准备一个专用的 WSL2 系统，用来容纳 PX4、Gazebo、工作进程和实验产物。它不会复用或修改用户个人的 Ubuntu。

准备页面会依次显示四种状态：

1. **Checking**：检查主机能力和磁盘条件；
2. **Preparing**：导入并配置隔离运行环境；
3. **Verifying**：检查必要服务和运行清单；
4. **Checked**：状态灯变为绿色，工作台按钮开放。

> 状态仍然是 **Checking** 时不要进入调优工作台。只有环境状态变成 **Checked**，进度才会到达 100%。

### 2.3 仅在需要时重新检查

进入工作台不会自动再次检查环境。需要重新检查时，打开 **设置**，找到 **本地运行环境**，再点击 **检查环境**。

## 3. 通过调优对话创建实验

调优对话可以把普通的需求描述转换成结构化实验草稿，适合已经知道目标行为、但不希望一开始就逐项填写全部字段的用户。

![调优对话](https://getdronedream.com/docs/zh-CN/tuning-chat.png)

### 3.1 描述实验需求

可以在文字或语音中说明：

- 飞行器和 PX4 版本；
- 轨迹形状、尺寸、高度和起点；
- 跟踪、速度、平滑度和鲁棒性的优先级；
- 风场、传感器噪声、载荷、电池和留出场景；
- 优化策略、试验预算和验收阈值。

**输入示例**

> 在 3 米高度让 x500 四旋翼沿半径 5 米的圆形赛道飞行，优先提高轨迹跟踪精度，加入中等强度的传感器噪声，并把总试验次数控制在 180 次以内。

### 3.2 审查提取结果

助手会返回：

- 一段简洁的实验概要；
- 可以直接从描述中填写的字段；
- 仍然缺失或存在歧义的决策；
- 用来打开实验草稿的按钮。

助手可以更新草稿，但不能自行创建运行任务或启动仿真。用户仍然需要进入五个环节复查配置，并明确点击创建实验。

### 3.3 语音与附件

点击麦克风按钮可以直接口述需求。加号菜单可以进入手动创建流程，也可以上传 JSON、文本、CSV、日志和图片等辅助材料。附件只为模型提供上下文，不能绕过字段校验。

## 4. 完成五个实验配置环节

手动创建流程适合希望直接控制每个字段的用户。每个环节都会独立校验输入并记录当前位置，因此重新打开草稿时会回到同一个实验上次停留的位置。

![飞行任务配置](https://getdronedream.com/docs/zh-CN/flight-setup.png)

### 4.1 飞行设置

选择经验等级、PX4 版本、机架、Gazebo 模型、世界、画面渲染方式、优化目标、权重和飞行轨迹。常见研究可以使用预设轨迹，需要精确坐标时可以选择自定义航点。

### 4.2 控制参数

只选择本次实验允许变化的控制参数。每一行都包含：

- PX4 参数名及可读的完整名称；
- 基线值；
- 搜索下限；
- 搜索上限；
- 相关或耦合参数。

搜索范围必须具有明确的物理意义，也要与试验预算相匹配。参数越多，搜索空间越大，通常需要更多仿真证据。

### 4.3 仿真场景

设置常规搜索、压力搜索、常规留出和组合压力留出场景，并根据需要配置风场、噪声、随机种子、载荷、电池、信号丢失、阵风和障碍物。

搜索场景用于指导优化，留出场景用于检查候选参数是否能适应没有直接参与搜索的条件。

### 4.4 约束与预算

选择仿真后端和优化策略，然后填写：

- 最大迭代次数；
- 每个候选的试验次数；
- 最大总试验次数；
- 目标 RMSE 和目标最大误差；
- 最低通过率。

右侧策略卡片会用纵向流程解释当前算法。模型供应商和 API Key 统一在 **设置** 中配置，不会重复出现在实验内部。

### 4.5 最终审查

审查页面汇总前四个环节。点击 **创建实验** 之前，需要逐项检查飞行器、搜索目标、场景、预算和全部 PX4 参数范围。

当参数数量超过一行可以展示的范围时，点击 **已选择的 PX4 参数** 标题即可查看完整列表。

## 5. 编辑自定义飞行轨迹

自定义轨迹编辑器同时提供坐标图和可编辑表格。图形区域与坐标表保持等高，表格中的 X、Y、Z 数值也会完整显示。

### 5.1 切换视图

使用坐标图右上角的控件切换 XY、XZ、YZ 和 3D 视图。3D 地面网格在两个方向使用相同的真实长度单位；轨迹延长时会增加正方形网格，而不是把原有网格拉成长方形。

### 5.2 精确编辑坐标

- 选中表格行时，对应航点会同步高亮；
- 直接在表格中修改 X、Y 或 Z；
- 使用加号添加航点；
- 使用撤销按钮恢复最近一次支持撤销的操作；
- 使用行内删除按钮移除指定航点。

### 5.3 导入或导出 JSON

坐标表上方的导入导出按钮可以与外部路径生成工具交换坐标数据。导入完成后，需要检查所有坐标再关闭编辑器。

## 6. 查看历史记录和实验依据

任务总览和历史报告会如实显示完成、失败和取消的实验。筛选器可以按状态、轨迹、目标、优化策略和日期缩小结果范围。

![任务总览](https://getdronedream.com/docs/zh-CN/dashboard.png)

每个完成的实验都应保留三层依据：

- **配置依据**：飞行器、固件、轨迹、参数范围、约束、策略和预算；
- **执行依据**：场景标识、随机种子、运行清单、进程日志和仿真产物；
- **决策依据**：可行性、跟踪误差、超调量、稳定时间、鲁棒性和 Pareto 权衡。

只有场景和指标契约兼容的实验才适合直接比较。验证条件不同，即使分数更低也不代表工程结果更好。

## 7. 账户、数据与安全边界

### 7.1 账户隔离

DroneDream 使用 Supabase 身份和行级安全策略隔离云端账户。社区话题按产品设计公开共享，而账户设置和用户拥有的云端记录仍然只属于创建者。

### 7.2 本地草稿

应用保持开启时，未完成的实验草稿会保留在侧边栏中，并可以回到原来的环节继续填写。如果用户在仍有草稿时关闭软件，DroneDream 会明确提示草稿将在退出后被丢弃。

### 7.3 模型凭据

供应商、模型名称和兼容 API Base URL 可以保存在设备上。API Key 只停留在当前应用会话中，不会被写入本地存储或实验草稿。

### 7.4 真实飞行之前

一次成功的优化结果只是后续验证的依据，不能直接成为部署许可。需要在独立 SITL 中复现实验结果，检查完整日志和失败场景，确认硬件限制，并遵循飞行器运营者的安全流程。
