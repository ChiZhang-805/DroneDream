# Uutela Coastal Forest runtime map

This exterior-only local-ENU map is generated from City of Helsinki building, road, tree, ecological-network, and avoindata:Ortoilmakuva_2026_5cm data under CC BY 4.0. Buildings use registered footprints and addresses; launch and handoff points are selected on the official road network. No indoor geometry or unverified doorway location is claimed.
